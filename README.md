# Il cartellino

Per ogni partita di Serie A, i 3 giocatori più probabili da ammonire, con formazioni ufficiali, storico dei tris e area personale.

Sito statico (una sola pagina, `index.html`) pubblicato su Vercel: ogni aggiornamento di questo repository viene ripubblicato in automatico.
I tris di ogni visitatore restano salvati nel suo browser.
